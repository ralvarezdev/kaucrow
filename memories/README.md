# Memories / Recuerdos

Write what you want to say about Javier in a file here, in Spanish or
English, and open a pull request. / Escribe lo que quieras decir de Javier
en un archivo aquí, en español o en inglés, y abre un pull request.

One file per person: `memories/your-name.md`. / Un archivo por persona:
`memories/tu-nombre.md`.

Use this shape, and skip whatever doesn't apply. / Usa esta forma y omite lo
que no aplique:

```md
# Your name / Tu nombre

How I knew Javier / Cómo conocí a Javier:

What I admired / Lo que admiraba de él:

What I remember / Lo que recuerdo:

What I appreciate, what I'm thankful for / Lo que aprecio, lo que agradezco:

A phrase for the page (optional) / Una frase para la página (opcional):
```

These files are not shown on the site yet; they are kept here and we will
decide together how to show them. / Estos archivos aún no se muestran en el
sitio; se guardan aquí y decidiremos juntos cómo mostrarlos.

Everything goes through a pull request and is read before it is merged. See
the main [README](../README.md#share-your-memories) / el [README](../README.es.md#comparte-tus-recuerdos) principal.
